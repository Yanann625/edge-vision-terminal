# 性能基准（优化前 vs 后）

> **这是整个项目唯一能让人记住的东西——必须填入真实数字。**
> 没有数据，前面所有回答都白搭。所有数字来自 `perf.c` 实测，方法见下。

## 测量方法

- 端到端延迟：`perf_stage` 在采集完成 / 处理完成 / 上报完成分段打点，统计均值、P95、P99、最大值
- CPU 占用：两次采样 `/proc/self/stat` 的 utime+stime 求差
- 帧率：单位时间出队帧数
- 内存：读 `/proc/self/status` 的 VmRSS
- 工具：`tools/perf_plot.py` 出图；`make` 时加 `-pg` 可用 gprof
